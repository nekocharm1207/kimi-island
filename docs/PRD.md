## 1. 产品概述

### 1.1 产品名称
**kimi-island**（暂定，内部代号）

### 1.2 一句话描述
一个常驻屏幕顶部的胶囊形浮动面板，实时展示 Kimi Code Console 的订阅额度与频限状态，像 iPhone 的 Dynamic Island 一样优雅地展开/收缩。

### 1.3 目标用户
- 每日高频使用 Kimi Code Console 的开发者
- 需要随时关注额度消耗、避免触发频限的用户
- 喜欢桌面小工具/浮动面板形态的用户

### 1.4 价值主张
> **不再频繁打开浏览器查额度，扫一眼屏幕顶部就知道还剩多少。**

## 2. 功能需求 (Functional Requirements)

### FR-01 紧凑模式（Compact Mode）—— 默认常驻态

| 属性 | 说明 |
|------|------|
| **触发条件** | 应用启动后默认进入；从展开模式收缩后回到此状态 |
| **窗口尺寸** | 320 × 48 逻辑像素（宽度可在设置中配置 240~480） |
| **窗口位置** | 当前首选显示器顶部水平居中，y = 0（贴顶） |
| **命中区域** | 胶囊形状（圆角矩形，肩部半径 6px），区域外鼠标穿透 |

**视觉元素（从左到右）**：

```
┌─────────────────────────────────────────┐
│  ┌───┐  ┌──────────────────────┐  ┌──┐  │
│  │ K │  │████████░░░░░░░░░░░░░░│  │72%│  │
│  └───┘  └──────────────────────┘  └──┘  │
└─────────────────────────────────────────┘
   Logo    额度进度条（绿/黄/红）   百分比
```

- **Logo**：Kimi 品牌 "K" 字标识，16×16px，白色
- **进度条**：
  - 宽度约 180px，高度 6px，圆角 3px
  - 颜色规则：
    - `> 30%`：绿色 `#10B981`
    - `10% ~ 30%`：黄色 `#F59E0B`（触发黄色预警）
    - `< 10%`：红色 `#EF4444`（触发红色预警）
- **百分比文字**：右侧，14px，等宽字体，白色

**交互行为**：
- Hover：背景色从 `#000000` @ 80% 透明度 → `#1F1F1F` @ 85%，过渡 200ms
- Click：切换至展开模式
- 预警状态下：边框产生脉冲呼吸动画（见 FR-04）

### FR-02 展开模式（Expanded Mode）—— 详情查看态

| 属性 | 说明 |
|------|------|
| **触发条件** | 点击紧凑胶囊 / Hover 停留 800ms / 额度预警自动弹出 |
| **窗口尺寸** | 420 × 280 逻辑像素（高度随内容自适应，最小 240，最大 400） |
| **命中区域** | 完整矩形窗口（全部可交互） |
| **过渡动画** | 从顶部居中位置向下展开，300ms ease-out，同时宽度从 320 过渡至 420 |

**内容布局（从上到下）**：

```
┌────────────────────────────────────────────┐
│  ┌──────────────────────────────────────┐  │
│  │  🟢 Kimi Pro          有效期至 06-15 │  │  ← 头部栏
│  └──────────────────────────────────────┘  │
│  ┌──────────────────────────────────────┐  │
│  │  本周额度                              │  │
│  │  ┌──────────────────────────────┐    │  │
│  │  │████████████░░░░░░░░░░░░░░░░░░│ 72% │  │  ← 额度卡片
│  │  └──────────────────────────────┘    │  │
│  │  已用 72K / 总额 100K                 │  │
│  └──────────────────────────────────────┘  │
│  ┌──────────────────────────────────────┐  │
│  │  频限状态                              │  │
│  │  RPM: 12/60    TPM: 2.3K/40K          │  │  ← 频限详情
│  │  RPD: 124/1000  状态: 正常             │  │
│  └──────────────────────────────────────┘  │
│  ┌──────────────────────────────────────┐  │
│  │  [🔄 刷新数据]  [🌐 打开 Kimi]  [⚙️]  │  │  ← 操作栏
│  └──────────────────────────────────────┘  │
└────────────────────────────────────────────┘
```

- **头部栏**：当前订阅计划名称 + 有效期倒计时
- **额度卡片**：大进度条 + 精确数值（支持单位自动转换：K/M）
- **频限详情**：RPM/TPM/RPD 当前值/上限，超限项标红
- **操作栏**：刷新按钮、打开 Kimi 网页按钮、设置按钮

**自动收缩**：鼠标离开展开面板 2000ms 后，自动收缩回紧凑模式（可配置关闭）。

### FR-03 数据获取与缓存策略

**数据来源**：本地 `kime check` 命令行工具（用户已安装）

**两种数据类型**：

| 类型 | 字段 | 刷新策略 |
|------|------|----------|
| **实时数据** | `weekly_usage`, `rate_limit_details`, `usage_ratio` | 定时轮询 |
| **缓存数据** | `current_plan`, `validity`, `model_permissions` | 订阅周期内不变 |

**轮询策略**：
- 默认间隔：60 秒
- 额度 `< 30%`：缩短至 30 秒
- 额度 `< 10%`：缩短至 15 秒
- 用户手动点击刷新：立即执行一次

**缓存机制**：
- 缓存文件：`%LocalAppData%\kimi-island\cache.json`
- TTL：缓存数据以 `subscription.currentEndTime` 为有效期
- 启动时先读缓存展示，再后台刷新

**降级策略**：
- kime CLI 调用失败 → 显示上次缓存数据 + 右上角"离线"徽章
- 首次启动无缓存且 CLI 失败 → 显示"请配置 kime"引导界面

### FR-04 额度预警系统

**预警阈值（可配置）**：
- 黄色预警：剩余额度 ≤ 30%（默认）
- 红色预警：剩余额度 ≤ 10%（默认）

**预警行为**：

| 预警级别 | 紧凑模式表现 | 展开模式表现 |
|----------|-------------|-------------|
| 正常 | 绿色进度条，无动画 | 正常展示 |
| 黄色 | 进度条变黄 + **边框脉冲动画** | 顶部显示黄色横幅"额度不足 30%" |
| 红色 | 进度条变红 + **边框快速脉冲** + 可选自动弹开 | 顶部显示红色横幅"额度不足 10%，请注意" |

**脉冲动画规格**：
- 黄色：边框颜色 `#F59E0B` → 透明，周期 2s，ease-in-out，无限循环
- 红色：边框颜色 `#EF4444` → 透明，周期 1s，ease-in-out，无限循环

### FR-05 系统托盘

**托盘图标**：Kimi "K" 字标识，16×16px，根据额度状态变色：
- 正常：白色
- 黄色预警：黄色
- 红色预警：红色

**右键菜单**：
- 显示 / 隐藏灵动岛
- 立即刷新数据
- 打开设置
- 退出应用

**左键单击**：切换灵动岛的显示/隐藏状态。

### FR-06 配置系统

**配置文件路径**：`%AppData%\kimi-island\config.json`

**配置项清单**：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `preferred_display` | string | `"primary"` | 首选显示器（primary / 显示器名称 / 索引） |
| `compact_width` | number | 320 | 紧凑模式宽度，范围 240~480 |
| `yellow_threshold` | number | 30 | 黄色预警阈值（%） |
| `red_threshold` | number | 10 | 红色预警阈值（%） |
| `poll_interval_normal` | number | 60 | 正常状态轮询间隔（秒） |
| `poll_interval_warning` | number | 30 | 预警状态轮询间隔（秒） |
| `poll_interval_critical` | number | 15 | 紧急状态轮询间隔（秒） |
| `auto_collapse_delay` | number | 2000 | 展开模式自动收缩延迟（毫秒），0 表示关闭 |
| `auto_expand_on_warning` | boolean | false | 预警时是否自动弹出展开模式 |
| `theme` | string | `"system"` | 主题：system / dark / light |
| `sound_on_warning` | boolean | false | 预警时是否播放提示音 |

**配置界面**：在展开模式中点击 ⚙️ 按钮打开设置弹窗，或双击托盘图标打开。

### FR-07 开机自启动

- 提供「开机自启动」开关（默认关闭）
- Windows 实现：写入注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
- 应用启动时最小化到托盘，不主动弹出窗口

## 3. 非功能需求 (Non-Functional Requirements)

### NFR-01 性能

| 指标 | 目标值 | 测试方法 |
|------|--------|----------|
| 内存占用 | 空闲 < 60MB，展开时 < 80MB | Task Manager 观测 |
| CPU 占用 | 空闲 < 0.5%，轮询时 < 3% | Task Manager 观测 |
| 启动时间 | 从点击到显示紧凑岛 < 2s | 秒表测量 |
| 展开/收缩动画 | 60fps，不掉帧 | 肉眼观测 + DevTools Performance |

### NFR-02 兼容性

- **操作系统**：Windows 10 版本 1809（Build 17763）及以上 / Windows 11
- **DPI 缩放**：支持 100%、125%、150%、175%、200%、225%、250%
- **多显示器**：支持多显示器环境，可指定首选显示器
- **高对比度模式**： gracefully degrade，确保文字可读

### NFR-03 可靠性

- 连续运行 7 天无内存泄漏（通过长期观测验证）
- kime CLI 调用失败时，应用不崩溃，优雅降级
- 配置文件中存在非法值时，自动回退到默认值并记录日志

### NFR-04 安全性

- 不存储用户的 JWT token，只读取 kime CLI 的配置
- 所有网络请求（如有）通过 HTTPS
- 不收集任何遥测数据（完全本地运行）

### 4.1 紧凑模式状态机

```
         ┌──────────────────┐
         │   紧凑模式(常驻)   │
         └────────┬─────────┘
                  │ Click / Hover 800ms
                  ▼
         ┌──────────────────┐
    ┌────│   展开模式(详情)   │────┐
    │    └────────┬─────────┘    │
    │Leave 2s/Click│              │ Click 刷新
    │             │              │
    ▼             │              ▼
┌──────────┐      │      ┌──────────────┐
│ 收缩动画  │◄─────┘      │ 显示刷新中... │
│ 回紧凑   │             │ 更新数据      │
└──────────┘             └──────────────┘
```

### 4.2 预警状态机

```
┌─────────┐    usage <= yellow    ┌─────────────┐
│  正常   │──────────────────────▶│  黄色预警   │
│ (绿色)  │◀────usage > yellow────│  (黄色脉冲) │
└─────────┘                       └──────┬──────┘
                                         │ usage <= red
                                         ▼
                                ┌─────────────┐
                                │  红色预警   │
                                │ (红色脉冲)  │
                                └─────────────┘
```

## 5. 术语表

| 术语 | 解释 |
|------|------|
| 灵动岛 (Dynamic Island) | 源于 iPhone 14 Pro 的交互概念，指屏幕顶部的可变形态浮动 UI |
| 紧凑模式 (Compact) | 灵动岛的收起状态，显示最精简的信息 |
| 展开模式 (Expanded) | 灵动岛的展开状态，显示完整详情 |
| 命中区域 (Hit Region) | 窗口中实际响应鼠标事件的区域，通过 `SetWindowRgn` 裁剪实现 |
| DPI 缩放 | Windows 的高分辨率屏幕适配机制，如 125%、150% |
| kime | 社区逆向的 Kimi Code Console CLI 工具，提供额度查询接口 |
| RPM / TPM / RPD | Rate Limit 指标：每分钟请求数 / 每百万 Token 数 / 每日请求数 |
